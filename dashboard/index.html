Launch Radar

Protocols with no token yet, ranked by what a launch would be worth — priced off the market that already trades.

How to read this board. Every implied value is this radar's own estimate, built only from the sealed snapshot's figures: a protocol's TVL, its category's market-cap-to-TVL multiple among tokens that already trade, its seven-day momentum, its age and its chain count. It is not a prediction that a token will be issued, or when. Farm plans are starting points, not financial advice — check each protocol's own page before committing funds.
